# ARPABET phoneme -> viseme class. Used by VisemeRescorer to identify
# viseme-equivalent words (the candidate set for LM rescoring of the
# CTC decoder output).
#
# Format: one line per phoneme, `<PHONEME>\t<VISEME>`. Lines starting
# with # are comments. The phoneme set matches Liperty's
# MLConstants.PHONEME_VOCAB (40-symbol ARPABET).
#
# Mapping based on Jeffers & Barley (1971), "Speechreading (Lipreading)",
# the most-cited grouping in lipreading research. Some adjustments from
# more recent corpus-based studies (Bear & Harvey 2017) where the
# Jeffers groups proved suboptimal for ASR rescoring:
#   - Velars (K, G, NG) collapsed with alveolars (T, D, N, L, S, Z)
#     because they're indistinguishable from outside the mouth.
#   - W and UW separated from other rounded vowels because the lip
#     protrusion is much more pronounced.
#
# Visemes are intentionally fewer than 14 — coarser groupings make
# more pairs viseme-equivalent, which makes the rescorer's candidate
# set richer at the cost of false positives. 9 classes is a balance
# point that's been validated on LRS2 (Bear-Harvey).
#
# Viseme legend:
#   V1 = vowels (most: a/e/i/short-o etc.)
#   V2 = bilabial closure (b/p/m)
#   V3 = post-alveolar (sh/ch/jh/zh)
#   V4 = alveolar+velar internal (t/d/n/l/s/z/k/g/ng)
#   V5 = dental (th/dh)
#   V6 = rhotic (r/er)
#   V7 = labio-dental (f/v)
#   V8 = glottal (hh)
#   V9 = rounded (uw/w)
